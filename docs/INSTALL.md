# التحميل والتثبيت — Install

> **بصيرة** تعمل على أندرويد، آيفون، وويندوز. اختر جهازك من الجدول.

## تحميل مباشر

| الجهاز | الطريقة | الرابط |
|---|---|---|
| **Android** | ملف APK (تثبيت كامل، يعمل أوفلاين) | **[تحميل APK](../../releases/latest)** |
| **iPhone / iPad** | PWA عبر Safari (إضافة إلى الشاشة الرئيسية) | **[افتح النسخة](https://mo3bdo23.github.io/basira/)** |
| **Windows** | PWA عبر Edge أو Chrome (تثبيت كتطبيق) | **[افتح النسخة](https://mo3bdo23.github.io/basira/)** |
| **أي جهاز آخر** | متصفح حديث | **[افتح النسخة](https://mo3bdo23.github.io/basira/)** |

---

## Android

1. حمّل ملف `basira-android.apk` من صفحة [الإصدارات](../../releases/latest).
2. افتح الملف من الإشعارات أو من مجلد «التنزيلات».
3. سيطلب النظام السماح بالتثبيت من هذا المصدر — اضغط **الإعدادات** ثم فعّل **السماح من هذا المصدر**.
4. اضغط **تثبيت**، ثم **فتح**.

**المتطلبات:** أندرويد 6.0 (Marshmallow) أو أحدث · مساحة ~40 ميجابايت.

**بعد التثبيت:** افتح التطبيق، اسمع الإخلاء ووافق، ثم اسمح بالموقع والميكروفون.

> إن ظهر تحذير «تطبيق من مصدر غير معروف» فهذا طبيعي لأي تطبيق لا يأتي من Google Play.
> بصيرة مفتوحة المصدر، ويمكنك مراجعة الكود كاملًا في هذا المستودع.

---

## iPhone / iPad

لا يمكن تثبيت تطبيقات iOS خارج App Store إلا عبر TestFlight أو شهادة مطوّر.
الحل الحالي هو **PWA** — يعمل بنفس الميزات الأساسية:

1. افتح الرابط في **Safari** (وليس Chrome).
2. اضغط زر **المشاركة** (مربع بسهم لأعلى).
3. اختر **إضافة إلى الشاشة الرئيسية**.
4. سمِّ التطبيق «بصيرة» ثم **إضافة**.

سيظهر كأيقونة على الشاشة الرئيسية ويعمل بملء الشاشة. الميزات المدعومة على iOS:
الصوت (TTS/STT)، الموقع، الخرائط المتجهية، البلاغات المحلية، والوضع الأوفلاين.
**غير مدعوم على iOS عبر الويب:** إرسال SMS تلقائيًا (يفتح تطبيق الرسائل بدلًا من ذلك).

---

## Windows

1. افتح الرابط في **Microsoft Edge** أو **Google Chrome**.
2. من شريط العنوان اضغط أيقونة **تثبيت** (شاشة صغيرة بسهم) أو من القائمة: **تطبيقات ← تثبيت هذا الموقع كتطبيق**.
3. سيظهر بصيرة في قائمة ابدأ كتطبيق مستقل.

---

## أي جهاز آخر (Linux / ماك / كروم بوك)

افتح [الرابط](https://mo3bdo23.github.io/basira/) في أي متصفح حديث. لا يحتاج تثبيت.

## للمطوّرين

```bash
# أندرويد
flutter build apk --release

# ويب
flutter build web --release --base-href "/basira/"

# iOS (يتطلب macOS + Xcode)
flutter build ios --release
```

## الأسئلة الشائعة

**هل يعمل بدون إنترنت؟**
نعم. بعد التحميل الأول، تعمل الخرائط والمسارات والبلاغات محليًا.

**هل يحتاج حسابًا؟**
لا. لا يوجد تسجيل دخول مطلوب.

**هل يُرسل بياناتي؟**
لا. التخزين مشفّر على جهازك، والموقع لا يُشارك إلا مع جهات اتصال SOS التي تضيفها.

**لماذا لا يوجد على Google Play أو App Store؟**
المشروع مفتوح المصدر ويُوزَّع مباشرة. النشر على المتاجر يحتاج حسابًا مدفوعًا ومراجعة.
