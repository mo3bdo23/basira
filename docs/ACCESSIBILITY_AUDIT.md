# تدقيق الإتاحة

> تدقيق ذاتي مقابل WCAG 2.1 AA. البنود الموسومة ⏳ تحتاج جهازًا حقيقيًا وقارئ شاشة.

## 1. الإدراك (Perceivable)

| المعيار | الحالة | كيف |
|---|---|---|
| 1.1.1 نص بديل | ✅ | `Semantics(label:)` لكل أيقونة/خريطة، ووصف نصي للخريطة المتجهية |
| 1.3.1 معلومات وعلاقات | ✅ | عناوين `Semantics(header: true)` وتجميع منطقي |
| 1.4.1 استخدام اللون | ✅ | كل حالة مصحوبة بنص/أيقونة، لا لون وحده |
| 1.4.3 تباين | ✅ | ≥ 4.5:1 (أخضر #0B6B3A على أبيض = 6.4:1) |
| 1.4.4 تغيير حجم النص | ✅ | `MediaQuery.withClampedTextScaling(0.9–1.6)` |
| 1.4.11 تباين غير النص | ✅ | حدود 1.5–4px، أهداف واضحة |

## 5. اختبار مع قارئ الشاشة

| السيناريو | TalkBack | VoiceOver |
|---|---|---|
| قراءة الشاشة الرئيسية بالكامل | ⏳ | ⏳ |
| بدء تنقل وإنهاؤه | ⏳ | ⏳ |
| تسجيل بلاغ | ⏳ | ⏳ |
| إضافة جهة اتصال | ⏳ | ⏳ |
| شاشة SOS | ⏳ | ⏳ |

> ⏳ = لم يُنفَّذ بعد على جهاز فعلي. هذا هو البند الأول في خطة v1.1.

## 6. أدوات مقترحة

- Android Accessibility Scanner.
- TalkBack + VoiceOver يدويًا.
- Flutter Semantics Debugger (`flutter run --debug` ثم `S`).

## 7. القيود المعلنة

- لا يوجد إرشاد اهتزازي كامل بديلًا عن الصوت (الاهتزاز مساعد فقط).
- دقة GPS قد تصل إلى 30 م خارج المباني.
- لا دعم بعد للغات غير العربية/الإنجليزية.
