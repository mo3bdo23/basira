# خريطة الطريق — Basira Roadmap

> الحالة الحالية: **v1.0** — الميزات الأساسية مكتملة وتعمل أوفلاين.

## v1.1 — التحقق المجتمعي والصقل (قريب)

- [x] عدّاد تأكيد/اعتراض للبلاغات (3 تأكيدات = مؤكد، 3 اعتراضات = مرفوض)
- [x] أنماط اهتزاز دلالية (يمين / يسار / خطر / إشارة / وصول)
- [x] مراقبة انقطاع GPS وتنبيه صوتي + إعلان الاستعادة
- [ ] لوحة تحقق للمتطوعين داخل التطبيق
- [ ] إشعارات FCM عند التحقق من بلاغ قريب

## v1.2 — دقة أعلى داخل المباني

- [ ] دعم **Bluetooth Beacons** عند المداخل ونقاط التفرّع (دقة ~1 م)
- [ ] معايرة تلقائية لمسار المشي داخل الحرم
- [ ] تسجيل مسار جديد من المستخدم (Record & Replay) للمسارات غير الموثّقة

## v1.3 — الذكاء الاصطناعي المساعد

- [ ] توصيف الصور بالكاميرا (on-device) للتعرف على اللوحات والعوائق
- [ ] كشف الإشارات الضوئية بالكاميرا كخطة بديلة عند غياب بيانات الإشارة
- [ ] مساعد حواري عربي يفهم «خذني لأقرب حمام» ويخطّط المسار

## v2.0 — المنظومة

- [ ] نسخة **ساعة ذكية** (Wear OS / watchOS) للاهتزاز والإرشاد القصير
- [ ] تكامل مع إشارات المرور الحكومية عبر واجهة بيانات مفتوحة
- [ ] دعم لغات إضافية (إنجليزية، فرنسية) مع نفس منطق الأوامر
- [ ] بوابة للجامعات لإدارة المباني والمسارات دون تحديث التطبيق

## أفكار مرفوضة مؤقتًا
