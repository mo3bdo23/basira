# العرض التجريبي — 3 دقائق

> **الهدف:** أن يشعر الحكام بتجربة المستخدم، لا أن يقرأوا شرائح.

## قبل الصعود

- [ ] هاتف مشحون ≥ 80%، الصوت أقصى.
- [ ] جهة اتصال SOS تجريبية (رقم زميل).
- [ ] التطبيق مفتوح على الرئيسية.
- [ ] مسار تجريبي 30–50 م داخل القاعة/الممر.
- [ ] فيديو احتياطي مسجّل.

## 0:00 — الخطاف (20 ث)

> «أغمضوا أعينكم ٣٠ ثانية. تخيلوا شارعًا لا تعرفونه، بلا إشارة تراها، بلا رصيف تثق فيه.
> ٨٠٠ ألف مصري يعيشون هذا كل يوم.»

## 0:20 — التعريف (15 ث)

> «بصيرة: تطبيق يسمعك، يرشدك، يحذّرك، ويطلب المساعدة عنك — بدون إنترنت وبدون لمس الشاشة.»

## 0:35 — الإقلاع (20 ث)

- «بصيرة. طريقك الآمن بصوتك» (يُسمع).
- شاشة إخلاء المسؤولية: «التطبيق يفرض قراءة الإخلاء صوتيًا — السلامة مسؤولية.»
- «أوافق».

## 0:55 — الأوامر الصوتية (25 ث)

- كرة الصوت → **«أين أنا؟»** → وصف الموقع وأقرب مبنى.
- **«ابدأ التنقل»** → قائمة مسارات بأسمائها ومسافاتها.

## 1:20 — الإرشاد (35 ث)

- اختر مسارًا → «امشِ ٤٠ مترًا ثم انعطف يمينًا» + اهتزاز يمين.
- امشِ خطوات حقيقية أمام الحكام.
- **أطفئ الواي فاي الآن**: يظهر «أوفلاين» والإرشاد يستمر.
- **«توقف»** → «تم إنهاء التنقل».

## 1:55 — الإشارات والبلاغات (25 ث)

- خريطة الجامعة → البوابة → دليل صوتي.
- «إشارة ميدان شبين الكوم على بعد ٣٠ مترًا، الضوء أحمر، انتظر ١٢ ثانية» + اهتزاز أحمر.
- بلّغ عن عائق → ميكروفون → «حفرة كبيرة في الرصيف» → «تم التسجيل، سيُرفع عند عودة الإنترنت».

## 2:20 — الطوارئ (20 ث)

- SOS → «سيُرسل موقعك خلال ٥ ثوان…» → «إلغاء» → «لم يُرسل موقعك.»
- «الإلغاء بنقرة — لا إنذارات كاذبة.»

## 2:40 — الخاتمة (20 ث)

> «بصيرة ليس تطبيق خرائط آخر. هو استقلالية: طالب يذهب لمحاضرته وحده، وأهل يطمئنون.
> الكود مفتوح المصدر، والتطبيق يعمل على أي هاتف أندرويد قديم.»

## أسئلة متوقعة

| السؤال | الإجابة |
|---|---|
| لو GPS غلط؟ | عتبة 25 م + إسقاط على المسار + Beacons في v1.2 |
| لو النت مقطوع؟ | كل البيانات في Hive، والبلاغات تُرفع لاحقًا |
| إيه اللي يمنع بلاغات كاذبة؟ | تحقق مجتمعي: 3 تأكيدات = مؤكد، 3 اعتراضات = مرفوض |
| الفرق عن Google Maps؟ | إرشاد عربي مصري، تنبيه إشارات، خرائط حرم، أوفلاين كامل، SOS |
| هل البيانات دقيقة؟ | بيانات تجريبية موثّقة كذلك، تحتاج تحققًا ميدانيًا |
| التكلفة؟ | صفر للتشغيل؛ Firebase Spark يكفي |
