## 4. المكوّنات

### Big Action Button
- الحجم: عرض كامل، ارتفاع ≥ 88.
- الحشو: 20/18.
- أيقونة داخل مربع 60×60 بزاوية 18.
- النص: Title L (23) + Hint (17).
- الحواف: 22، حدود 1.5 `outlineVariant`.
- حالة focus: حدود 4 `primary`.

### Voice Orb
- قطر 132 + هالة 158.
- تدرّج primary.
- نبض 6% عند الاستماع/النطق.
- أيقونة: mic / volume_up / mic_none.

### SOS Button
- قطر 108 (و190 في شاشة الاستغاثة).
- تدرّج `#E53935 → #8E0000`.
- حد أبيض 4.
- نص «SOS» 22% من القطر.

### Status Pill
- شرائح صغيرة 30px radius، أيقونة 18 + نص 15.
- ألوان: أخضر متصل، رمادي بدون GPS، أحمر خطأ.

### Instruction Card (Navigation)
- تدرّج primary، زاوية 24، حشو 20.
- نص التعليم 27/800 أبيض.
- 3 إحصاءات: المتبقي، الزمن، التقدم.
- شريط تقدم 10px.

### Campus Map
- ارتفاع 300، زاوية 20.
- خلفية `surfaceContainerHighest` 45%.
- شبكة 48px.
- مبانٍ 40×30 بزوايا 9.
- «أنت هنا» دائرة 11 حمراء بإطار أبيض.

## 5. الشاشات (Frames)
