# دليل الإتاحة

## 1. المبدأ

> «لا شيء عنّا بدوننا» — كل ميزة يجب أن تُستخدم **بالسمع فقط**، بلا استثناء.

## 2. قائمة التحقق قبل كل إصدار

### التسميات
- [ ] كل زر له `Semantics(label:)` بلغة مفهومة (لا «أيقونة ٤»).
- [ ] كل صورة/خريطة لها وصف نصي بديل.
- [ ] الحقول لها `labelText` لا `hintText` فقط.
- [ ] الأخطاء تُعلن صوتيًا لا تُعرض بصريًا فقط.

### التنقل
- [ ] كل شاشة تُعلن اسمها عند الفتح (`AppScaffold`).
- [ ] ترتيب التركيز منطقي (يمين ← يسار في RTL).
- [ ] زر الرجوع واضح ومُعلَن.
- [ ] لا عنصر تفاعلي مخفي خلف تمرير أفقي فقط.

### اللمس
- [ ] هدف اللمس ≥ 48dp (المستخدم هنا 88dp للأزرار الرئيسية).
- [ ] مسافة ≥ 8dp بين الأهداف المتجاورة.
- [ ] لا اعتماد على الضغط المطول فقط (SOS له ضغط عادي + مطول).

### الصوت
- [ ] معدل النطق قابل للتعديل (20%–100%).
- [ ] لا نص يُنطق أسرع من اللازم دون خيار.
- [ ] التنبيهات العاجلة تقطع الطابور، والعادية تُنتظر.
- [ ] الصوت يعمل مع السماعة الخارجية والبلوتوث.

### البصر
- [ ] تباين ≥ 4.5:1 لكل نص.
- [ ] وضع «أصفر على أسود» متاح.
- [ ] لا اعتماد على اللون وحده (كل حالة لها نص/أيقونة).

### الحركة
- [ ] لا وميض > 3 مرات/ثانية.
- [ ] الرسوم المتحركة لا تعيق القراءة.

## 3. الاختبار مع TalkBack (Android)

```
1. الإعدادات ← الإتاحة ← TalkBack ← تشغيل
2. افتح بصيرة
3. اسحب بإصبع واحد: يجب أن تسمع كل عنصر باسمه
4. اضغط مرتين: يُنفّذ
5. جرّب كل شاشة لمدة دقيقة على الأقل
```

**معايير القبول:** يمكن إتمام المهام التالية دون رؤية الشاشة:
- الوصول من الإقلاع إلى الرئيسية.
- بدء تنقل وإنهاؤه.
- تسجيل بلاغ.
- إضافة جهة اتصال SOS.
- تغيير سرعة النطق.

## 4. الاختبار مع VoiceOver (iOS)

```
1. الإعدادات ← الإتاحة ← VoiceOver
2. نفس السيناريوهات
3. انتبه: VoiceOver يقرأ تلقائيًا عند التركيز — لا تكرر النطق مرتين
```

> **ملاحظة تقنية:** عند تفعيل قارئ الشاشة، قد يتعارض نطق التطبيق (TTS) مع نطق النظام.
> الحل الحالي: `A11yService.announce` للنظام + `TtsService` للتعليمات الطويلة،
> مع خيار «القراءة عند التحديد» لتقليل التكرار.

## 5. خيارات الإتاحة في التطبيق

| الخيار | الأثر |
|---|---|
| سرعة النطق | 20%–100% |
| حِدّة الصوت | 0.6–1.6 |
| أسلوب الإرشاد | مختصر / متوسط / مفصّل |
| القراءة عند التحديد | يقرأ العنصر عند وصول focus |
| الاهتزاز الدلالي | نمط مختلف للخطر |
| التباين العالي | أصفر/أسود |
| المظهر | فاتح/داكن/النظام |
| مدة عدّ SOS | 3–15 ثانية |

## 6. ما لا يفعله التطبيق (حدود معلنة)

- لا يكتشف العوائق تلقائيًا بالكاميرا (ليس بديلًا عن العصا).
- لا يعمل بدون صوت (لا يوجد بديل اهتزازي كامل بعد).
- لا يدعم بعد اللغات غير العربية والإنجليزية للواجهة.
