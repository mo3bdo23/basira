# خطة المشروع — 5 أسابيع · فريق 5 أشخاص

**المنهجية:** Design Thinking (Empathize → Define → Ideate → Prototype → Test) داخل سبرنتات Agile أسبوعية.

## تشكيل الفريق

| الدور | المسؤوليات |
|---|---|
| **قائد المشروع + Flutter** | المعمارية، الشاشات، التكامل |
| **مطوّر Flutter ثانٍ** | الخدمات، الأوفلاين، المزامنة |
| **مصمّم UI/UX** | Figma، نظام التصميم، إتاحة بصرية، اختبار التباين |
| **مسؤول المحتوى والبيانات** | نصوص الإرشاد الصوتي، بيانات الجامعات والمسارات، التوثيق |
| **مسؤول الاختبار والميدان** | خطة الاختبار، التنسيق مع مدرسة النور، الديمو، العرض |

- صفر حوادث سلامة أثناء الاختبار.
- رضا المستخدمين ≥ 4/5.
